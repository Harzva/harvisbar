# 磁盘根目录快捷操作：架构设计

## 调用链

`DiskInfo.volumeURL` → `VolumeRootActions` → 剪贴板 / `NSWorkspace` → `diskUsageRow` 两个 SwiftUI 按钮。

## 模块职责

| 文件 | 职责 |
| --- | --- |
| `Models/RuntimeModels.swift` | 提供磁盘名、容量和规范挂载根 URL |
| `Runtime/VolumeRootActions.swift` | 将复制与打开动作集中为可注入、可测试的小服务 |
| `MenuBar/HarvisSystemPopoverSection.swift` | 呈现两个图标按钮、提示文本和无障碍标签 |
| `Tests/HarvisBarTests/VolumeRootActionsTests.swift` | 验证传给系统能力的是准确根路径/URL |

## 数据流与契约

```text
mounted volume URL
       │
       ▼
   DiskInfo
       │
       ├── copy → URL.path → NSPasteboard string
       └── open → URL      → NSWorkspace.open
```

- `copyRootPath` 返回底层剪贴板写入结果，界面本次不增加反馈状态。
- `openRoot` 返回底层 Finder 打开结果，界面本次不增加错误弹窗。
- 动作服务通过闭包注入系统边界，使测试不真正改写剪贴板或打开 Finder。

## ADR

| 取舍 | 决定与原因 |
| --- | --- |
| 打开目录而非选中目录 | 使用 `NSWorkspace.open`，符合“打开对应路径”的语义 |
| 不从盘名构造路径 | `volumeURL` 已是系统提供的权威挂载根 |
| 独立动作服务 | 隔离 AppKit 副作用并允许确定性单元测试 |
| 保留整行点击 | 避免改变已有交互习惯 |

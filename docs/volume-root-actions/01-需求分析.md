# 磁盘根目录快捷操作：需求分析

## 目标

在 HarvisBar「System」面板的每个本地磁盘条目中增加两个紧凑图标按钮：

- 复制该磁盘挂载根路径；
- 在 Finder 中打开该磁盘根目录。

例如系统盘复制 `/`，合成测试中的外置盘复制 `/Volumes/Example Disk`。

## 做与不做

| ID | 需求 | 验收方式 |
| --- | --- | --- |
| R1 | 每个磁盘行显示复制路径按钮 | SwiftUI 源码检查与构建 |
| R2 | 复制内容严格等于 `DiskInfo.volumeURL.path` | 单元测试 |
| R3 | 每个磁盘行显示 Finder 打开按钮 | SwiftUI 源码检查与构建 |
| R4 | 打开的 URL 严格等于 `DiskInfo.volumeURL` | 单元测试 |
| R5 | 按钮保持紧凑，并有 tooltip 与无障碍标签 | 源码检查 |
| R6 | 原有整行点击 Finder 定位行为保持不变 | 回归检查 |

不新增设置项、确认弹窗、路径编辑能力，也不改变磁盘扫描和排序逻辑。

## 约束与边界

- 路径可能包含空格或非 ASCII 字符，直接使用 `URL.path`，不做 shell 转义。
- 系统盘根路径为 `/`，不能用盘名拼接推导。
- 复制和打开是本机即时操作，不写入配置或日志。
- 当前 Harvis 仓库已有大量其他未提交修改；本任务不覆盖或整理它们。

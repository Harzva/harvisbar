## 6. 风险登记

| 风险 | 影响 | 缓解 |
| --- | --- | --- |
| canonical 工作树正在恢复且存在较多脏改动 | 误覆盖或难以归因 | 只修改本计划文件，使用独立构建目录，不 reset/clean |
| 运行缓存与 canonical 源码条目数不同 | 新 Swift 连旧 Host 时 launch descriptor 缺失 | 可选解码并显示明确空态；最终安装需从同一 canonical revision 构建 Host + Bar |
| Finder 启动应用的 PATH 不完整 | CLI 误判缺失 | 白名单解析合并当前 PATH 与受限的常见用户/系统 bin 目录 |
| Desktop bundle 名称变化 | 已安装但无法发现 | bundle ID 优先，受管 app name 回退，单测覆盖 |
| 弹窗宽度不足 | 按钮被截断 | 分段切换、固定尾按钮、文本 lineLimit |

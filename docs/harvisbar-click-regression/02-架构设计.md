# HarvisBar 闭环点击回归：架构设计

## 分层

```text
版本/打包契约
  ↓
交互清单（页面 + 控件 + 风险等级）
  ↓
隔离 UI Host + 动作记录器
  ↓
AX 点击驱动 + 结果断言 + 状态恢复
  ↓
正式包 live smoke + 安装/进程/日志验证
```

## 模块职责

| 模块 | 职责 |
| --- | --- |
| 版本契约 | 统一 workspace、package、bundle、extension、receipt 版本，防止降级/假升级 |
| 包元数据契约 | 固定 bundle ID、权限用途描述、资源清单和签名策略 |
| 交互清单 | 以稳定 ID/AX label 枚举全部控件、预期结果、副作用和恢复策略 |
| 隔离 UI Host | 在普通窗口显示真实 Popover 组合，避免 MenuBarExtra 屏外 AX 限制 |
| 动作记录器 | 在测试模式拦截高风险外部动作，记录规范化意图，不执行真实破坏性操作 |
| AX 驱动 | 按页面定位、点击/输入/选择，读取实际 UI 结果 |
| live smoke | 在正式包中覆盖启动、导航、低风险真实外部动作和一个完整刷新周期 |

## 依赖方向

```text
View → HarvisRuntimeModel → Action/Transport/File abstractions
Test Driver → AX labels / stable test IDs
Test Driver → Action log / OS-observable result
Package Verifier → Info.plist / receipt / provenance / codesign
```

View 不反向依赖测试驱动；测试模式通过注入动作 sink 或受控环境启用，正式默认路径不改变。

## 数据流

1. 驱动器选择页面并读取当前元素清单。
2. 通过 AXPress/键盘输入执行交互。
3. 低风险 live 动作从 OS 窗口、剪贴板、HTTP 或进程状态取证。
4. 高风险动作在隔离模式写入无敏感信息的 action log，由驱动器断言。
5. 恢复剪贴板、主题、设置、窗口和临时目录，再进入下一项。

## 风险等级

| 级别 | 示例 | 策略 |
| --- | --- | --- |
| R0 纯 UI | 切页、展开、刷新可见状态 | 正式包真实点击 |
| R1 可恢复 | 复制、改主题、打开 Finder/本地页 | 保存原状态，真实点击后恢复 |
| R2 本地变更 | 临时快捷目录、临时凭据、服务重启 | 专用测试 profile/workspace，结束清理 |
| R3 外部/高风险 | 登录、归档、任务投递、系统扩展、模型调用 | 隔离 action sink 或验证禁用/确认门，不使用真实用户数据 |

## 配置契约

- 隔离模式必须显式命令行开关开启，不得通过普通用户配置误启用。
- action log 只记录 action ID 和脱敏后参数，不记录 token/凭据值。
- 测试 workspace/profile 必须在临时目录，不复用用户真实写入目录。
- 正式包验证依旧要求 clean provenance stage、receipt 和 strict codesign。

## ADR

| 决策 | 原因 |
| --- | --- |
| 隔离 host 与正式 live smoke 两层验收 | MenuBarExtra 的屏外 AX 不稳定；只用隔离 host 又无法证明安装包生效 |
| 高风险动作使用 action sink | 完整点击覆盖不应以真实登录、凭据或任务执行为代价 |
| 以交互清单为覆盖分母 | 避免用“有多少测试”替代“有多少入口真正被测” |
| 版本契约进入自动门 | 防止再出现新包 `0.33.0` 而旧包 `0.34.0` 的无意降级 |

# HarvisBar 闭环点击回归：开发计划

## 阶段总览

| Phase | 目标 | 验收门 |
| --- | --- | --- |
| 0 | 建立版本、包与交互基线 | 正式/备份/源码差异和全控件清单可审计 |
| 1 | 修复版本、Info.plist、AX 与已知细节缺口 | 契约测试先失败后通过，无未标签按钮 |
| 2 | 建立可重复的隔离点击驱动 | 12 页和全局入口可稳定定位，R3 动作无真实副作用 |
| 3 | 跑完整交互矩阵并修复失败 | 每个清单项有 pass/blocked/fail 和证据，fail=0 |
| 4 | 重新打包、安装、重启与 live 回归 | 正式进程唯一，版本一致，低风险真实点击全通，无崩溃/循环错误 |
| 5 | 总验收与报告 | `05-验收报告.md` 逐项对照，无未解释遗漏 |

## Phase 0：基线审计

- [ ] 记录当前正式进程、安装路径、版本、签名、entitlements、receipt/provenance。
- [ ] 比较正式 `0.33.0`、旧备份 `0.34.0`、当前源码与 Release 产物的功能差异。
- [ ] 静态枚举所有 Button/Toggle/Picker/Menu/Link/TextField/drop target/gesture/shortcut。
- [ ] 按 12 页和全局区域生成交互矩阵，标注 R0–R3。
- [ ] 执行正式包首轮只读 AX 枚举和可逆点击，记录缺失/未标签/不可达项。

验收标准：交互清单有明确分母；所有差异有证据，不用“感觉缺少”代替定位。

不做：不在未完成基线前盲目覆盖正式 App。

## Phase 1：契约与细节修复

- [ ] 确定并统一正确版本，增加防降级契约测试。
- [ ] 恢复打包 Info.plist 必需用途描述，纳入 bundle verifier。
- [ ] 为所有图标/动态按钮提供稳定且唯一的 AX label/value/hint。
- [ ] 过滤失效卷，消除周期性 `Invalid volume` 错误。
- [ ] 修复 Phase 0 定位的页面、路由、禁用条件与文案问题。

验收标准：契约测试、全量 Swift 测试和 Release build 通过；正式 UI 不再暴露 `<unlabeled>` 按钮。

不做：不在无 Apple 证书时伪造可用的 Network/System Extension 能力。

## Phase 2：隔离点击驱动

- [ ] 在受控命令行开关下，以普通窗口显示真实 HarvisPopoverView。
- [ ] 增加测试 workspace/profile 和临时数据 fixture。
- [ ] 对 R3 动作注入记录 sink，并确保正式模式不受影响。
- [ ] 驱动器支持切页、滚动、点击、输入、菜单选择、等待终态和证据采集。
- [ ] 驱动器每项后执行恢复钩子，失败时也要恢复。

验收标准：连续运行两次产生同一控件分母和结果；无真实 R3 副作用。

不做：不把不稳定坐标当成主定位方式。

## Phase 3：完整交互回归

- [ ] 运行 12 页及全局操作的全量点击矩阵。
- [ ] 对每个控件记录 enabled/disabled 原因和实际结果。
- [ ] 对复制、打开路径/URL、服务刷新/重启做 OS 级断言。
- [ ] 对表单验证空值、非法值、有效值与取消路径。
- [ ] 修复全部 fail 并从头重跑，不只重跑失败子集。

验收标准：清单分母中 fail=0；blocked 仅限真实外部条件，且有明确安全门证据。

不做：不用手工截图替代机器可读断言。

## Phase 4：正式发布与 live 回归

- [ ] 从当前已验证工作树创建隔离干净发布快照。
- [ ] 执行全量测试、Release build、provenance stage、打包、strict verify。
- [ ] 保留旧正式包作为可恢复备份，切换登录项并只启动正式路径。
- [ ] 在正式进程上重跑 R0/R1 点击与必需 R2 smoke。
- [ ] 验证剪贴板/Finder/本地页面/窗口/服务结果，再恢复环境。
- [ ] 连续观测一个完整刷新周期，检查 crash/spawn failure/重复实例/循环日志。

验收标准：安装包与源码/回归产物同源，正式 live 回归全通。

不做：不在旧进程存活时打开新包。

## Phase 5：总验收

- [ ] 将所有清单项、缺口、修复、测试命令与证据写入 `05-验收报告.md`。
- [ ] 对照 `01-需求分析.md` 逐项勾选。
- [ ] 记录仅由外部条件导致的 blocked 项及用户可见影响。

验收标准：无未解释的功能缺失、版本错误或细节回归。

## 风险登记

| 风险 | 影响 | 对策 |
| --- | --- | --- |
| 仓库有并发变更 | 测试与安装的不是同一份源码 | 每个发布门记录 HEAD + status digest + artifact SHA |
| MenuBarExtra AX 不完整 | 屏外按钮无法稳定点击 | 隔离 window host + 正式 live 双层验收 |
| 本机无 Apple 签名身份 | 系统扩展无法完整验收 | 明确 blocked，验证 UI 不伪报可用；其余功能不降级 |
| 真实账户/凭据副作用 | 泄露、登录变更或实际任务执行 | 临时 profile + action sink + 脱敏报告 |
| 无效卷/Full Disk Access | 磁盘项假失败、循环日志 | 可达性过滤 + Info.plist 用途描述 + live 卷回归 |
